# product-images

## 目标
判断购买决策档案是否缺少产品图，并在需要时补图。

## 什么时候用
- 用户明确说“加图片 / 补图 / 真机图 / 封面图”
- 页面当前没有 cover 或 supporting 资产
- 某个重点区块需要视觉支撑

## 执行顺序
1. 检查当前文档是否已有可用图片
2. 没有则发起搜图
3. 把图片写入资产池或图片区块
4. 验证 `assets` 或图片区块是否真的发生变化

## 输出要求
- 必须返回是否真的补图成功
- 成功时给出命中图片类型和绑定位置
- 失败时给出原因与下一步建议

## 失败回退
- 搜图失败时，要求用户上传资料或接受无图版本
